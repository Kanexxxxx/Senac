# UC5 — Lógica de Programação

## Organização das pastas

- `OOP/`: exercícios de Programação Orientada a Objetos.
  - `rascunhos/`: versões iniciais mantidas apenas como referência.
- `programasNode/`: programas executados no terminal com Node.js.
- `JS/`: arquivos JavaScript usados pelas páginas HTML.
- `html/`: páginas dos exercícios web.
- `CSS/`: estilos das páginas.
- `IMG/`: imagens usadas nos exercícios.
- `lupes/`: exercícios sobre estruturas de repetição.

## Como executar programas Node

Na pasta principal do projeto, use:

```powershell
node .\UC5\programasNode\nome-do-arquivo.js
```

Exemplo:

```powershell
node .\UC5\programasNode\ProcessadorDePagamentos.js
```
