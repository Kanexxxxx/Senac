## Executar

Consulte as instruções e os arquivos de cada atividade. Exercícios HTML podem ser
abertos no navegador; scripts de terminal exigem o runtime correspondente.
Na [UC5](UC5/README.md), confira também `package.json` antes de instalar dependências.
Não existe um comando de execução ou uma suíte de testes única para todo o acervo.

## Manutenção

Preserve o enunciado, a unidade e o objetivo didático de cada atividade. Diferencie
exemplo, exercício incompleto e solução; sem essa classificação, semelhança de código
não é motivo suficiente para reunir exercícios independentes.
